## Contact form deployment

The `/api/contact` endpoint forwards submissions to Formspree. If `RECAPTCHA_SECRET_KEY` is configured, it verifies the reCAPTCHA token server-side; without that secret, it requires a token from the browser widget but cannot validate it server-side. On Vercel, it uses `api/contact.ts`. On LiteSpeed or Apache hosting, the built `public/api/contact.php` endpoint is routed by `public/api/.htaccess`; PHP cURL must be enabled. Optionally configure `CONTACT_FORM_ENDPOINT` as a server-side environment variable. Never expose the reCAPTCHA secret with a `VITE_` prefix or commit it to the repository. The Formspree destination defaults to `https://formspree.io/f/xdeoyjbe`.

The regular Vite development server does not execute API functions or PHP. Use `vercel dev` to test the Vercel function locally, or test against the PHP-enabled hosting environment.
